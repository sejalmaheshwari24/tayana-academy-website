What it does

How you build it

Four steps, one shipped demo.

Ingest & chunk the corpus
Load your documents, split them into retrievable chunks, and choose an embedding model. Set up the vector store.
Retrieve & rank
On each question, embed the query, pull the most relevant chunks, and rank them before they reach the model.
Generate with citations
Prompt the model to answer only from retrieved context, and attach a citation to the exact source passage.
Evaluate & harden
Run an eval set for faithfulness and retrieval quality. Catch hallucinations before the demo ships.
